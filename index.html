JavaScript - Eventos Teclas.

El evento de teclas baja o keydown se dispara cuando se presiona una tecla del teclado. A diferencia del evento keypress, que se limita a las teclas que generan caracteres visibles, el evento keydown se dispara para todas las teclas, incluyendo las teclas de control como Shift, Ctrl, Esc, Tab y entre otras.

Escucha de eventos.

Para capturar y responder a un evento, debes escuchar dicho evento en un elemento específico del DOM (Document Object Model). Esto se hace mediante la función: addEventListener.

addEventListener()


La función addEventListener es una herramienta esencial en JavaScript para manejar eventos y crear interactividad en tus documentos. Permite vincular funciones conocidas como manejadores de eventos, a elementos HTML específicos para responder a diferentes tipos de acciones realizadas por el usuario.

Uso keydown


En este ejemplo, evento keydown se escucha en el elemento body y mostrará en la consola del navegador la tecla presionada. 

const body = document.querySelector('body');
body.addEventListener('keydown',(event)=>{
console.log(`La tecla presionada es:${event.key}`);
})

En: 

const body = document.querySelector('body');

Estamos seleccionando el elemento body del documento HTML y guardándolo en la variable body.

En: 

body.addEventListener('keydown',(event)=>{});

Estamos agregando un manejador de eventos al elemento body que espera el evento keydown. Cuando se produce el evento keydown una tecla del teclado es presionada, se ejecuta el código dentro de la función del evento.

Dentro de la función, utilizamos consolelog() para imprimir en la consola del navegador un mensaje que indica qué tecla se ha presionado. La propiedad key del objeto event contiene el valor de la tecla presionada. 

console.log(`La tecla presionada es:${event.key}`);


Propiedades del evento keydown

Cuando se dispara el evento keydown, se genera un objeto que contiene varias propiedades útiles:

  • key - El valor de la tecla que se presionó (ej. a, Enter).

  • code - El código físico de la tecla (ej. KeyA, ArrowDown).

  • altkey - Booleano que indica si la tecla Alt estaba presionada.

  • ctrlKey - Booleano que indica si la tecla Control estaba presionada.

  • shiftKey - Booleano que indica si la tecla Shift esta presionada.

Listado de eventos teclas

  • keydown - Se dispara cuando se presiona una tecla. Este evento se activa inmediatamente cuando se presiona la tecla, antes de que se procese cualquir otro comportamiento.

  • keypress - Este evento se dispara cuando se presiona una tecla que podía generar un carácter es decir, una tecla alfanumérica. Sin embargo, este evento está obsoleto en favor de keydown y keyup.

  • keyup - Se dispara cuando se suelta una tecla que había sido presionada previamente. Este evento se activa una vez que la tecla se libera.

Ejercicios

En todos los ejercicios, todos los elementos deben ser creados y manipulados exclusivamente desde el archivo JavaScript. El archivo HTML solo debe contener la estructura mínima básica y la vinculación con el archivo JavaScript correspondiente.

  1. Realice un documento que escuche las teclas presionadas por el usuario. La función encargada de manejar este evento debe recibir un parámetro llamado event, visualice el parámetro por consola con la propiedad key.

  2. Crea un documento que muestre en un div la tecla que el usuario ha presionado en su teclado.

  3. Teniendo como base el ejercicio anterior, modifica el código para que, en lugar de mostrar solo una tecla presionada, muestre todas las teclas presionadas en secuencia. Es decir, debe ir escribiendo y mostrando en pantalla todo el texto que el usuario vaya ingresando.

  4. Implementa un documento donde un div pueda ser desplazado de izquierda a derecha y de arriba hacia abajo, usando las las flechas del teclado.

  5. Desarrolla un documento que cuente y muestre el número de veces que el usuari ha presionado una tecla específica, la tecla a.

  6. Realice un programa que detecte cuando el usuario presione la tecla b y, en función de ello, alterne el estado de la página entre modo claro y modo oscuro. El fondo, el título y los parrafos deben cambiar de color según el estado activo.

  7. Crea un documento que detecte y responda a combinaciones específicas de teclas como: Ctrl + s y al presionar la combinación mostrara el siguiente mensaje Documento Guardado en el cuerpo del documento .

  8. Desarrolla un documento que al presionar una tecla numérica del 1 al 5 cambie el color de fondo del documento a un color predefinido diferente para cada número.

  9. Crea un documento que reproduzca un sonido específico cuando se presione cualquier tecla.
